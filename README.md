# Schoen Heating & Air Conditioning Inc Concept — HVAC Website

A standalone Next.js concept project tailored to Schoen Heating & Air Conditioning Inc. It includes the full `src` app and pnpm lockfile.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project notes

- Business details, palette, services, coverage, and calls to action are in `src/config/site.config.ts`.
- The supplied Schoen wordmark and red service-van hero photo are bundled locally in `public/brand` and `public/hero`. The favicon uses the Schoen red, yellow, and navy identity.
- The request form is a preview and does not send submissions. The service-area map uses OpenStreetMap tiles and needs internet access.
- Confirm all business details before publishing.

Original website: https://www.schoenheatingandair.net/
